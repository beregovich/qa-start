# QA Start — интерактивная входная диагностика

Статический сайт без внешних библиотек, сборки, сервера, базы данных и аналитики. Содержит 47 вопросов (44 диагностических и 3 завершающих).

## Запуск

Откройте `index.html` в браузере. Для публикации:

1. Создайте публичный репозиторий на GitHub, например `qa-start`.
2. Загрузите в корень репозитория файл `index.html` (README можно загрузить вместе с ним).
3. Откройте **Settings → Pages → Build and deployment**.
4. В пункте **Source** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем **Save**.
5. После публикации ссылка обычно будет вида `https://USERNAME.github.io/qa-start/`.

Для приватного репозитория возможность использования GitHub Pages зависит от плана GitHub и настроек. Публичная страница общедоступна, **но ответы не публикуются**: они хранятся в локальном хранилище браузера и экспортируются только по действию пользователя.

## Как передать результаты

Перейти в раздел «Завершение» и нажать **Скачать JSON** (предпочтительно) или **Скачать TXT**. Прикрепить файл к переписке с наставником / ChatGPT. Экспорт работает даже при наличии незаполненных пунктов.

## Безопасность и ограничения

- Автоматическое сохранение — `localStorage` в браузере, не облако; при очистке данных сайта ответы могут исчезнуть.
- Не предусмотрена автоматическая отправка данных, оценивание, учётные записи и восстановление с другого устройства.
- На совместном компьютере после выгрузки используйте «Очистить ответы».
- Не включайте персональные данные, которые не хотите передавать.
- Код и опубликованная страница в публичном репозитории видны всем, но выгруженные ответы остаются у заполняющего, пока он сам их не отправит.
